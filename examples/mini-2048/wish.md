# 许愿需求：点开就能玩的极简 2048 网页小游戏

## 我想要什么

帮我做一个**点开浏览器就能直接玩**的 2048 小游戏：

1. **玩法与体验**
   - 经典 4×4 棋盘，支持键盘方向键和 `WASD` 操作，也支持鼠标/触屏滑动；
   - 每次有效移动在随机空格生成 `2`（90%）或 `4`（10%），同数字方块碰撞合并得分；
   - 支持 **「撤回一步」** 和 **「重新开始」** 按钮；
   - 实时显示当前分数和历史最高分（用浏览器 `localStorage` 自动记住，刷新不丢）；
   - 合成 `2048` 弹出胜利祝贺（可选择继续挑战更高分或重来），无路可走时弹出结束提示。
2. **视觉风格**
   - 清爽现代的浅色质感界面，不同数字方块有舒适区分色，合并和移动有轻量过渡动画，手机和电脑居中自适应。
3. **交付与运行要求**
   - **零第三方依赖、零编译**：纯原生 HTML / CSS / JavaScript，项目根目录或 `web/` 下提供 `index.html` 与一个启动脚本（或直接 `python3 -m http.server` 即可游玩）；
   - **工程化质量**：把棋盘状态契约（`contracts/`）、纯游戏逻辑引擎（`engine/`）和网页交互界面（`web/`）清晰解耦；核心引擎用本机 Node.js 22 内置 `node --test` 跑通完整单元测试。
