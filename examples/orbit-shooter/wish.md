# 碎星航线

开发一个可以离线打开的竖屏街机射击游戏。玩家驾驶飞船，在星带中移动并击碎陨石。键盘方向键或 WASD 移动，空格发射；手机拖动飞船并自动开火。每次命中计分，飞船碰撞会损失护盾并短暂无敌，三次失误后结束。随分数逐步增加难度。提供暂停、继续、重新开始和本地最高分。

把状态与输入契约放在 contracts/，确定性的模拟逻辑放在 engine/，Canvas 绘制与交互放在 web/。从 web/index.html 直接打开即可游玩，无联网及编译依赖。用 node --test tests/*.test.cjs 验证移动边界、射击冷却、命中与得分、碰撞保护、暂停和复位。

本次交付采用文件模式。每个任务只修改蓝图授权的文件，显式接收上游产物并返回自己的修改。验收要求真实 LoopForge Run、测试通过、键盘与触屏可用的游戏目录。
