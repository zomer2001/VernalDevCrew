# 功能规格

## 目标
保存用户对项目澄清问题的回答，重新进入页面后可以继续查看。

## 用户场景
- 负责人填写回答并提交，页面显示保存成功。
- 负责人重新进入页面，看到最近保存的回答。

## Non-Goals
- 本轮不提供多人同时编辑。
- 本轮不接入外部知识库。

## 需求
### REQ-001 [P0] 保存回答
要求：当负责人提交非空回答时，系统应保存回答并返回确认。
验收：
- 提交后返回保存成功。
- 重启服务后仍可以读取同一回答。

### REQ-002 [P1] 拒绝空回答
要求：当负责人提交空白回答时，系统应提示填写有效内容。
验收：
- 提交空白回答返回校验错误，原有回答保持不变。

## 边界情况
- 保存失败时应显示错误，不得显示保存成功。
