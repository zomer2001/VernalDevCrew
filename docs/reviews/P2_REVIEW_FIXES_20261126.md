## 兼容和耗时处理

1. 已发布工作包不通过修改原冻结快照来迁移。旧版派生文档指纹仅在原提示词版本、匹配预设版本、没有后续资产升级且来源仍有效时兼容。
2. 首次评估后按推荐锁定预设属于正常流程。该步骤会同步更新评估检查点，不再把本次主动锁定误认为并发输入变化。
3. 改变模型或角色推理设置会刷新规划资产配置，派发请求指纹也包含执行器、模型与推理强度，避免复用不同配置的旧请求。
4. 不同强度采用独立原生快照，避免并行任务互相改写共享角色。快照内容相同时不重复注册，读取原流程以保留后续人工修改。
5. 恢复请求遇到不确定回包后停止重复提交，并显示需要核对远端状态，减少无效审批请求。
