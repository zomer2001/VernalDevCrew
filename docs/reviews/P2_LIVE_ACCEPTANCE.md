## 根因与修复

1. **异步按钮恢复失败。** 浏览器事件分发结束后，`event.currentTarget` 会变为 null。原实现等待接口后再从事件取按钮，导致成功检查和失败提交均可能抛出异常。现在在等待前保存按钮引用，并阻止进行中的重复点击。
2. **空回答提示不明确。** 新增前端必填与长度校验，后端校验继续保留。失败后保留当前输入并允许重试。
3. **验收夹具没有原生项目绑定。** 旧脚本默认向隐藏的入口工作区写题，用户打开网页却看不到。脚本现在默认只启动服务；需要夹具时，必须明确指定已绑定的独立项目。重复准备不会重置回答。
4. **回答后的旧判断仍在展示。** 等待重新评估时隐藏旧的范围与风险判断，避免把过期结论显示为当前结论。
5. **导航及版本提示混乱。** 工作台的下一步指引进入需求交付面板，回答 Diff 只展示保存结果，不混用内部修订 ID 与规格版本号。

后台身份衔接属于运行环境问题：隔离工作区没有原部署被 Git 忽略的身份文件。本次复用了同一执行服务的已有身份，运行文件权限为 0600，位于忽略路径，没有签发新身份或提交凭据。页面预检查确认该身份可以连接执行服务。
