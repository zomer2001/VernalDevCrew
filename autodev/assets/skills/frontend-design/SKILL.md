# Frontend Design & Craftsmanship

编写前端页面、Web 应用或网页游戏界面时，严格遵守以下设计与工程准则：

1. **拒绝廉价 AI 模板味**：
   - 严禁默认堆砌刺眼的蓝紫霓虹渐变、无意义发光阴影或杂乱 Emoji。
   - 先确立清晰的视觉基调（例如清爽精密蓝图风、高对比度街机风、温暖纸感卡片风），全站保持统一的字号阶梯、圆角半径与留白节奏。
2. **色彩与可读性对比度**：
   - 明确定义背景色（Canvas）、卡片底色（Surface）、主强调色（Primary Accent）与状态语义色（成功/警告/危险），使用 CSS 变量集中管理。
   - 正文与背景对比度必须清晰易读，按钮悬停（`:hover`）、按下（`:active`）与键盘聚焦（`:focus-visible`）均需具备明确视觉反馈。
3. **自适应与多端输入兼容**：
   - 桌面宽屏与窄屏手机视口（`375px ~ 1440px`）均不得出现横向溢出裁切或控件遮挡。
   - 交互组件与游戏画布同步兼顾键盘快捷键、鼠标点击拖拽及移动端触屏手势（必要时设置 `touch-action: none` 防止误触页面滚动）。
4. **零外部失效资源**：
   - 在离线或沙箱环境下，严禁依赖可能加载失败的外网 CDN 图片或字体链接；图标优先使用内联 SVG 或 CSS 绘制。
